**The two scheduled soundness/verification backstops run again, on GitHub Actions (ADR-117 follow-up).** `gate-a-full-replay` and `independent-check-backstop` both targeted `namespace-profile-unsorry-1`, which has had zero runners since the namespace.so trial ended, so their daily crons queued forever — `gate-a-full-replay` in particular is the ADR-048 Phase 2 defense-in-depth backstop (full kernel replay + full axiom audit over the whole active library), and it had been silently dead.

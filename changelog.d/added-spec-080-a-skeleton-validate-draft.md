Added SPEC-080-A (Draft) — `skeleton-validate`, the curated-package intake validator implementing ADR-080. Specifies a deterministic, stdlib-only `python3 -m tools.intake.skeleton_validate <package-dir>` that admits or rejects a submitted skeleton package whole: manifest well-formed; curated-target provenance (keeps ADR-078 scoring farm-proof); every obligation a well-formed open `sorry` goal; decomposition edges sound, acyclic, rooted, no orphans; no over-decomposition padding; and (under `--build`) the top statement type-checks under the pinned verifier context. Mirrors Gate B's CLI/exit-code contract, reuses existing AISP parsing + edge-walking, and runs both as an intake tool and a CI check on the package PR. Correctness stays the kernel's job at Gate A; this only checks the package is structurally a real, consumable, curated skeleton.

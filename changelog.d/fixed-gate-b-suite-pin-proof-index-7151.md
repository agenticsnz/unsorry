**Gate B now resolves and validates a suite-pin proof's index entry (ADR-099/ADR-116, #7151).** A benchmark obligation — and, through the decomposition graph, its sub-lemmas — proves at its suite's own toolchain+mathlib pin, so `check_in_proof` writes both the proof module and its `index/<sha>.aisp` entry into `targets/<suite>/_verify/library/`. Gate B resolved the proof index only under the repo `library/index/` and archive packages, so it reported `GB006` on the goal record and `GB020` on the proof-run against a correct, locally-verified, kernel-checked suite-pin proof. The harness then mapped that submission-side rejection onto its prove-failed path and **decomposed the already-proved goal**, discarding the proof and creating sub-goals that ADR-018 makes permanent. `tools/leaderboard/registered_targets.py` already counted suite indices as proved, so Gate B was the last component still assuming a single repo-wide index. Suite index entries are now also *scanned* rather than merely tolerated — previously a malformed artifact under `targets/*/_verify/library/index/` was never read at all.

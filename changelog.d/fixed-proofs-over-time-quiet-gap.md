Fixed **ADR-111 + SPEC-111-A (Proofs-Over-Time Quiet-Gap Carry-Forward)**: the `docs/proofs-over-time.svg` chart now distinguishes a quiet stretch (no new proofs landing) from a frozen chart. Its x-axis right edge tracks the latest board-source activity (`_latest_source_commit_z`, the same timestamp that keys `generated_at`) instead of stopping at the last proof, carrying the cumulative line flat to the edge as a dashed "no new proofs" segment with an edge tick at the activity time, and the subtitle gains `· last proof <ts> UTC`. Anchoring to the source-commit time (not wall-clock `now`) keeps the SVG deterministic for `--check` and adds zero commit churn — it advances only in lockstep with an input merge that already regenerates the board.

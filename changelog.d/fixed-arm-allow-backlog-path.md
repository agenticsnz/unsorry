**Fix: prove PRs with a `backlog/` note are no longer stranded un-merged (ADR-105 / ADR-068).** Queued / seedkit prove branches add a `backlog/<goal>.md` tracking note alongside the proof, but the auto-arm allow-list (`finalization_recovery.py` / `fork_automerge.py`) only permitted `library/ goals/ proof-runs/`. So `within_allow` rejected every such PR (`should_arm`/`is_admissible` → false), the finalization-recovery janitor found 0 arm candidates, and 40 green-and-mergeable prove PRs stranded for ~11 h — saturating the open-PR budget, which paused the submission governor and halted *all* new dispatch (no singletons, no batches). `backlog/` (benign markdown, not CODEOWNERS-gated) is now an allowed prove-PR path, so the janitor arms and merges these again.

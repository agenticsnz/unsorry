Added **ADR-112 + SPEC-112-A (Bounded Auto-Retry for a Flaked Required Gate)**: a sibling to the dropped-gate janitor that recovers PRs left `BLOCKED` when Gate A's full-Mathlib replay *flakes* (runs and fails for an infrastructure reason — runner eviction, cache miss, timeout — on a sound proof). The dropped-gate janitor only rescues gates that were never *dispatched*; a flaked *failure* previously had no automated recovery, so a sound PR sat `BLOCKED` indefinitely (2026-06-29: seven sound `mac-158f` difficulty-1 proofs sat ~63 h, freezing the swarm's proof landings, until a manual re-run cleared them). `tools/repo/flaky_gate_retry.py` + `.github/workflows/gate-a-flake-retry.yml` re-run the failed jobs (`gh run rerun --failed`) of a flaked required gate on an open, non-draft, auto-merge-enabled, `BLOCKED`/`UNKNOWN` PR, **bounded** by the workflow run's `run_attempt` so a genuinely failing proof is retried at most `--max-attempts` (default 3) before being left `BLOCKED` and surfaced — no infinite loop. Triggered by `workflow_run` on gate-a + hourly backstop + manual; shares the janitor's pure pending/failed predicates. Status: Accepted.

The independent-check bootstrap (`tools/independent_check/setup.sh`, ADR-096) now ensures a C linker (`cc`) is present before building lean4export and nanoda, via a new `ensure_cc` (`swarm/lib/ensure_cc.sh`) sibling of `ensure_lake`/`ensure_cargo`. Previously the bootstrap self-installed elan and Rust but assumed `cc`, so on a box without a C toolchain the nanoda build died deep in compilation with a cryptic `linker \`cc\` not found` and the kernel-diverse check was silently skipped. `ensure_cc` best-effort installs a minimal toolchain non-interactively on Linux (apt/dnf/yum/pacman/zypper/apk, root or passwordless `sudo -n` only — never hangs on a password prompt) and otherwise fails fast with the exact per-OS command (e.g. `xcode-select --install` on macOS). The supervisor's skip message now names the C toolchain alongside lake/cargo.

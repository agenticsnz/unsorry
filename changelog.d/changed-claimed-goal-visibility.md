A `--goal`-scoped prover that finds no work because the named goal is already claimed now says so: it logs which agent holds the live claim and when that claim expires (and flags the case where the holder is this agent's own orphaned claim), instead of only the generic "no viable or recoverable prove work this pass". With one live claim blocking all other agents (cap 1, ADR-017), this turns a silent idle into a clear "in flight, not missing" signal. Backed by a new read-only `py_helper claimants <goal> <claims-dir>` primitive.
